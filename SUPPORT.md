# Support policy / Politique d’assistance

## English

The desktop **Help → Report a problem** action prepares an editable report
locally. Nothing is sent automatically. Its optional anonymized diagnostics are
off by default. Review the complete text, then copy it or save it as UTF-8.

No official support-page URL is configured in the application. Use only an
official project channel you already trust; the application does not infer a
channel from Git metadata. For a reproducible bug, include the exact command,
exit code, error code, operating system/architecture, Python version, and
renderer identities when known.

Do not post confidential Markdown, PDFs, CSS, paths, tokens, or personal data.
Security issues belong in the private process in `SECURITY.md`; conduct reports
belong in the private process in `CODE_OF_CONDUCT.md`.

The project is pre-release and maintained on a best-effort basis. No response or
resolution time is guaranteed. Source-development help does not establish an
official platform-support promise. Only platforms that pass their native release
gate may be described as supported.

## Français

L’action **Aide → Signaler un problème** prépare un rapport modifiable en local.
Rien n’est envoyé automatiquement. Le diagnostic anonymisé facultatif est
décoché par défaut. Vérifiez le texte complet, puis copiez-le ou enregistrez-le
en UTF-8.

Aucune URL officielle de page d’assistance n’est configurée dans l’application.
Utilisez uniquement un canal officiel du projet auquel vous faites déjà
confiance ; l’application ne déduit aucun canal des métadonnées Git. Pour un bug
reproductible, indiquez si possible la commande exacte, le code de sortie, le
code d’erreur, le système et son architecture, la version de Python et les
identités du moteur.

Ne publiez aucun Markdown, PDF ou CSS confidentiel, chemin, jeton ou donnée
personnelle. Les problèmes de sécurité suivent le processus privé de
`SECURITY.md` ; les signalements de conduite suivent celui de
`CODE_OF_CONDUCT.md`.

Le projet est en version préliminaire et maintenu au mieux des disponibilités.
Aucun délai de réponse ou de résolution n’est garanti. L’aide au développement
depuis les sources ne constitue pas une promesse de prise en charge d’une
plateforme. Seules les plateformes ayant réussi leur validation native peuvent
être présentées comme prises en charge.
