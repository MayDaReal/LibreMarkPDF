# Roadmap

LibreMark PDF has no promised release date. The active priorities are:

1. Promote `0.1.0rc1` to a stable `v0.1.0` only after release-candidate feedback
   and both native validation lanes remain green.
2. Add Authenticode signing for Windows while retaining signed checksums, SBOMs,
   offline operation, and explicit platform limits.
3. Consider additional Linux matrices or macOS only through separate native
   build, packaging, signing, and validation work.

See [`docs/VALIDATION.md`](docs/VALIDATION.md),
[`docs/RELEASE.md`](docs/RELEASE.md), and
[`docs/PLATFORM_SUPPORT.md`](docs/PLATFORM_SUPPORT.md).
