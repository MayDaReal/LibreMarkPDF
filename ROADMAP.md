# Roadmap

LibreMark PDF has no promised release date. The active priorities are:

1. Keep deterministic local conversion and the canonical regression corpus.
2. Publish and maintain independently validated Windows x64 and Ubuntu 24.04
   x86_64 releases with checksums, SBOMs, signatures, and accurate limits.
3. Evaluate a fully local, tablet-first Android application without promising
   support before its rendering, storage, offline, packaging, and signing
   feasibility has been demonstrated.
4. Consider additional Linux matrices, smartphone layouts, macOS, and other
   platforms only through separate native validation work.

See [`docs/VALIDATION.md`](docs/VALIDATION.md),
[`docs/RELEASE.md`](docs/RELEASE.md), and
[`docs/PLATFORM_SUPPORT.md`](docs/PLATFORM_SUPPORT.md).
